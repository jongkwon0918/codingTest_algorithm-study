### 1. 친구의 친구까지 세기

사람은 0번부터 n-1번까지이며 friends[i].charAt(j)가 'Y'이면 i와 j는 직접 친구다.
두 사람이 직접 친구이거나, 두 사람 모두와 직접 친구인 사람이 한 명 이상 있으면
서로 '2-친구'라고 한다. 즉 친구 관계를 한 번 또는 두 번 이어 도달하는 다른 사람이다.
같은 사람을 여러 경로로 알게 되어도 한 번만 세며 자기 자신은 제외한다.
각 사람의 2-친구 수 중 최댓값을 반환하라. 사람 번호를 반환하는 문제가 아니다.
세 번 이상 관계를 이어야만 만나는 사람은 세지 않는다.

제한사항
- 1 <= friends.length <= 50
- 각 문자열 길이는 n이고 문자는 'Y' 또는 'N'이다.
- 자기 자신과는 친구가 아니므로 friends[i].charAt(i)는 'N'이다.
- 친구 관계는 양방향이다.

입출력 예시
{"NYNNN","YNYNN","NYNYN","NNYNY","NNNYN"} -> 4
관계는 0-1-2-3-4다. 2번의 2-친구는 0,1,3,4로 4명이다.
0번은 1,2만 포함하고 3,4는 포함하지 않는다.
{"NNN","NNN","NNN"} -> 0
{"NYY","YNY","YYN"} -> 2

### 2. 여덟 가지 이동으로 만나기

0번부터 100000번까지 돌이 일렬로 있다. start에서 goal로 이동하려고 한다.
현재 위치가 x일 때 한 번의 동작으로 다음 중 하나를 선택할 수 있다.
x-1, x+1, x-a, x+a, x-b, x+b, x*a, x*b.
한 동작에 여러 방법을 이어서 사용하지 않는다. 같은 방법은 여러 번 사용할 수 있다.
0보다 작거나 100000보다 큰 위치로 이동할 수 없다.
goal에 도달하는 최소 동작 수를 반환하라. 처음부터 같은 위치이면 0이다.

제한사항
- 2 <= a,b <= 30
- 0 <= start,goal <= 100000
- 모든 입력에서 목표에 도달할 수 있다.

입출력 예시
a=2,b=3,start=1,goal=6 -> 2
1 -> 3 -> 6처럼 두 번 이동한다.
a=2,b=3,start=10,goal=7 -> 1
a=2,b=3,start=0,goal=0 -> 0

### 3. 조건을 차례대로 적용하는 약속 장소

1번부터 n번까지 장소와 양방향 도로가 있다. roads[i]={a,b,time}이다.
지헌이는 j에서, 성하는 s에서 동시에 출발해 한 장소에서 만나려고 한다.
각 사람은 해당 장소까지 최단 시간으로 이동한다. 다음 조건을 반드시 순서대로 적용하라.
1. j와 s는 만날 장소 후보에서 제외한다. 두 사람이 모두 도달할 수 있는 장소만 후보가 된다.
2. 후보 전체에서 두 사람의 최단 이동 시간 합이 가장 작은 장소들만 남긴다.
3. 그중 지헌이의 이동 시간이 성하보다 긴 장소를 제외한다. 두 시간이 같으면 가능하다.
4. 남은 곳 중 지헌이의 이동 시간이 가장 작은 장소를 선택한다.
5. 그래도 여러 곳이면 번호가 가장 작은 장소를 선택한다.
선택한 장소 번호를 반환하고, 남은 곳이 없으면 -1을 반환하라.
중요: 3번에서 모두 탈락했다고 시간 합이 더 큰 장소를 다시 고르면 안 된다.

제한사항
- 2 <= n <= 100, 1 <= roads.length <= 1000
- 1 <= a,b,j,s <= n, 1 <= time <= 10000
- 같은 장소 사이 도로가 여러 개여도 처리해야 한다.
- 지헌이와 성하는 서로 만날 수 있는 입력이다. 선택 조건에 맞는 제3의 장소가 있다는 뜻은 아니다.

입출력 예시
n=4, roads={{1,2,2},{2,4,2},{1,3,2},{3,4,2}}, j=1,s=4 -> 2
2,3은 모두 시간 합4, 지헌이 시간2라서 번호가 작은2를 선택한다.
n=4, roads={{1,2,4},{4,2,1},{1,3,3},{4,3,3}}, j=1,s=4 -> -1
2번은 합5지만 지헌이가 늦어 탈락한다. 3번은 합6이므로 다시 후보로 선택할 수 없다.
n=3, roads={{1,2,2},{2,3,2}}, j=1,s=3 -> 2

### 4. 순환 노선까지 몇 정거장

1번부터 n번까지 역과 양방향 구간 n개가 있다. connections[i]={a,b}이다.
전체 노선은 연결되어 있고 고리는 정확히 하나다. 고리에 속하지 않는 역들은 가지처럼 이어져 있다.
고리는 같은 구간을 되돌아가지 않고 여러 역을 거쳐 출발 역으로 돌아올 수 있는 노선이다.
이 문제에서는 자기 연결과 중복 구간이 없으므로 고리는 최소 서로 다른 역3개와 구간3개로 이루어진다.
예: 1 -> 2 -> 3 -> 1은 고리다. 출발 역을 제외한 중간 역은 중복하지 않는다.
반면 1 -> 2 -> 1은 같은 구간을 왕복한 것이므로 고리가 아니다.
각 역에서 고리에 속한 역까지 이동해야 하는 최소 구간 수를 구하라.
고리에 속한 역의 답은 0이다. 역1번부터 n번 순서로 길이 n의 배열을 반환하라.
구간마다 이동 비용은1이며 자기 자신으로 연결된 구간과 중복 구간은 없다.

제한사항
- 3 <= n <= 3000
- connections.length == n
- 1 <= a,b <= n, a != b
- 모든 역은 서로 이동할 수 있고 고리는 정확히 하나다.

입출력 예시
n=6, connections={{1,2},{2,3},{3,1},{3,4},{4,5},{2,6}} -> {0,0,0,1,2,1}
1-2-3-1이 고리이고 5번은 4번을 거쳐3번까지 두 구간이다.
n=3, connections={{1,2},{2,3},{3,1}} -> {0,0,0}

### 5. 냄새를 따라 움직이는 상어들

n*n 격자에 1번부터 m번까지 상어가 한 마리씩 있다. board[r][c]는 상어 번호이고 0은 빈칸이다.
directions[id-1]은 id번 상어의 처음 방향이다. 방향 번호는1=위,2=아래,3=왼쪽,4=오른쪽이다.
priorities[id-1][direction-1]은 그 상어가 해당 방향을 보고 있을 때 검사할 방향4개의 순서다.
각 행의 값은1~4가 한 번씩 등장한다. 예를 들어 {4,1,3,2}는 오른쪽,위,왼쪽,아래 순서다.
방향은 실제로 이동한 방향으로 바뀐다.

시작 시 모든 상어는 자기 칸에 냄새를 남긴다. 냄새는 주인 번호와 남은 시간을 가지며 k초 유지된다.
매초 다음 처리를 반복한다.
1. 모든 상어가 이동 직전의 같은 냄새 지도를 보고 상하좌우 중 다음 칸을 선택한다.
   먼저 범위 안의 냄새 없는 칸을 우선순위대로 찾는다.
   그런 칸이 전혀 없으면 자기 냄새가 있는 칸을 같은 우선순위대로 찾는다.
   다른 상어의 냄새가 있는 칸은 선택하지 않는다.
2. 모든 상어가 동시에 한 칸 이동한다. 같은 칸에 모이면 가장 작은 번호만 살아남는다.
3. 기존 냄새의 남은 시간이1 줄어든다. 0이 되면 사라진다.
4. 살아남은 상어의 도착 칸에 주인 번호와 남은 시간 k를 기록한다.
냄새가1초 남은 칸도 이번 이동 결정 때는 냄새가 있는 칸이다.
도중에 사라진 상어의 예전 냄새는 남은 시간이 끝날 때까지 유지된다.
1번 상어만 남게 되는 최소 시간을 반환하라. 정확히1000초에 성공하면1000,
1000초가 지나도 다른 상어가 있으면 -1이다.

제한사항
- 2 <= n <= 20, 2 <= m <= n*n, 1 <= k <= 1000
- board에는1~m이 각각 정확히 한 번 등장한다.
- directions.length == m, priorities는 m*4*4 배열이다.
- 방향 값은1~4다.
- 처음에는 모든 상어에게 상하좌우 인접한 빈칸이 하나 이상 있다.

입출력 예시
board={{0,0,0},{1,0,2},{0,0,0}}, directions={4,3}, k=2
1번의 모든 방향별 우선순위={4,1,2,3}, 2번은 모두{3,1,2,4} -> 1
두 상어가 중앙(1,1)에 동시에 이동하여1번만 남는다.
Main의 두 번째 예제 -> 26
