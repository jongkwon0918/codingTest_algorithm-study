## 문제 풀이 영역

### 1. 여섯 자리 숫자 만들기

5*5 숫자판의 각 칸에 0부터 9까지의 숫자가 적혀 있다.
아무 칸에서 출발해 상하좌우 인접 칸으로 정확히 다섯 번 이동한다.
출발 칸을 포함해 지나온 여섯 칸의 숫자를 순서대로 붙여 여섯 자리 문자열을 만든다.
이미 지나온 칸을 다시 방문해도 되며, 000123처럼 0으로 시작해도 된다.
서로 다른 여섯 자리 문자열을 몇 개 만들 수 있는지 반환하라.
같은 문자열을 여러 이동 경로로 만들어도 한 번만 센다.

제한사항
- board는 5*5 배열이며 모든 값은 0 이상 9 이하이다.

입출력 예시
모든 칸이 0인 판 -> 1 (000000만 가능)
모든 칸이 1인 판 -> 1 (111111만 가능)
모든 칸이 1이고 (3,3)만 2인 판 (좌표 0부터) -> 15

### 2. 걸어서 또는 정거장으로 이동하기

1부터 n까지 일렬로 놓인 지점들이 있고 각 지점에는 정거장이 있다.
현재 위치가 x이면 x-1 또는 x+1로 걸어서 이동할 수 있다. 범위 밖으로는 나갈 수 없다.
teleports[i]={a,b}이면 a와 b 사이를 양방향으로 바로 이동할 수도 있다.
걷기 한 번과 정거장 이동 한 번은 모두 1초가 걸린다.
start에서 target까지 가는 최소 시간을 반환하라.
한 지점에 여러 정거장 연결이 있을 수 있다.

제한사항
- 2 <= n <= 300,000
- 0 <= teleports.length <= min(n*(n-1)/2, 300,000)
- 모든 지점 번호는 1 이상 n 이하이다.
- start != target, 각 연결의 두 지점은 서로 다르다.
- 같은 두 지점을 잇는 연결은 중복되지 않는다.

입출력 예시
n=10, teleports={{1,8},{8,10}}, start=1,target=10 -> 2
n=5, teleports={}, start=1,target=5 -> 4
n=10, teleports={{1,8},{8,10}}, start=10,target=1 -> 2

### 3. 파동으로 목표에 닿기

직사각형 교실에서 '*'는 주난이, '#'는 목표 학생, '0'은 빈칸, '1'은 다른 학생이다.
주난이는 자기 자리에서 반복해서 점프한다. 점프 한 번의 파동은 상하좌우 인접 칸을 따라
빈칸을 계속 통과하며 모든 방향으로 퍼진다. 중간에서 방향을 바꿔 퍼지는 것도 가능하다.
파동이 학생을 만나면 그 학생을 쓰러뜨리고 그 칸 너머로는 같은 점프에서 진행하지 않는다.
쓰러진 '1'은 다음 점프부터 빈칸처럼 통과할 수 있다.
한 점프에서 만난 여러 학생은 함께 쓰러진다. '#'에 파동이 닿으면 목표를 잡는다.
목표를 잡기 위한 최소 점프 횟수를 반환하라. 주난이가 직접 걸어가는 문제가 아니다.
start와 target은 각각 {행,열}이며 원본처럼 1부터 시작한다.

제한사항
- 행과 열의 길이는 각각 1 이상 300 이하이다.
- 모든 행의 길이는 같고 문자는 0,1,*,# 중 하나이다.
- '*'와 '#'는 각각 하나이며 서로 다른 위치이다.
- start와 target은 각각 '*'와 '#'의 위치이다.

입출력 예시
classroom={"*00#"}, start={1,1},target={1,4} -> 1
빈칸을 모두 통과해 첫 점프에 목표를 잡는다.
classroom={"*11#"}, start={1,1},target={1,4} -> 3
첫 점프에 첫 학생, 다음 점프에 둘째 학생, 세 번째에 목표를 잡는다.
classroom={"#0000","11111","0000*"}, start={3,5},target={1,1} -> 2

### 4. 세 칸짜리 무기를 겹치지 않게 만들기

직사각형 나무판의 각 칸에 강도가 적혀 있다.
세 칸을 사용하는 ㄱ 모양 부메랑을 여러 개 만들려고 한다.
부메랑 하나는 중심 한 칸, 중심의 위 또는 아래 한 칸, 중심의 왼쪽 또는 오른쪽 한 칸으로 구성된다.
따라서 중심을 기준으로 위+왼쪽, 위+오른쪽, 아래+왼쪽, 아래+오른쪽의 네 모양이 가능하다.
강도는 중심 칸의 강도*2 + 나머지 두 칸의 강도이다.
서로 다른 부메랑끼리 칸을 공유할 수 없다. 나무판의 일부 칸을 사용하지 않아도 된다.
만들 수 있는 부메랑들의 강도 합의 최댓값을 반환하라. 하나도 못 만들면 0이다.

제한사항
- 행과 열의 길이는 각각 1 이상 5 이하이다.
- 모든 행 길이는 같고 각 칸의 강도는 1 이상 100 이하이다.

입출력 예시
wood={{1,2},{3,4}} -> 13
(1,1)의 4를 중심으로 위쪽 2, 왼쪽 3을 사용하면 4*2+2+3=13이다.
wood={{7}} -> 0
wood={{32,83,75},{24,96,56},{71,88,12}} -> 632

### 5. 위치와 방향을 함께 맞추기

직사각형 공장에서 0은 로봇이 갈 수 있는 칸, 1은 갈 수 없는 칸이다.
로봇은 위치와 바라보는 방향을 가진다. 한 번의 명령으로 다음 중 하나를 수행한다.
- 현재 방향으로 1칸, 2칸 또는 3칸 전진한다. 이동 중 지나가는 모든 칸이 통과 가능해야 한다.
- 제자리에서 왼쪽으로 90도 또는 오른쪽으로 90도 회전한다.
180도 회전은 한 명령이 아니며, 뒤로 걷는 명령도 없다.
start와 target은 각각 {행,열,방향}이다.
행과 열은 원본처럼 1부터 시작하고, 방향은 동=1, 서=2, 남=3, 북=4이다.
목표 위치에 도착하는 것뿐 아니라 목표 방향까지 맞추는 최소 명령 횟수를 반환하라.

제한사항
- 행과 열의 길이는 각각 1 이상 100 이하이다.
- 모든 행 길이는 같고 각 값은 0 또는 1이다.
- 출발 칸과 도착 칸은 0이며 항상 목표까지 이동할 수 있다.

입출력 예시
factory={{0,0,0,0}}, start={1,1,1},target={1,4,1} -> 1
동쪽으로 세 칸 전진하는 명령 한 번이면 된다.
factory={{0}}, start={1,1,1},target={1,1,2} -> 2
같은 칸에서 동→남→서 또는 동→북→서로 두 번 회전해야 한다.
factory가 3*3 모두 0, start={3,1,1},target={1,3,4} -> 3
