### 1. 순서를 구분해서 숫자 고르기

1부터 n까지의 서로 다른 자연수 중 m개를 골라 나열하는 모든 방법을 반환하라.
한 수열 안에서 같은 숫자를 두 번 사용할 수 없다.
선택한 숫자가 같아도 순서가 다르면 다른 수열이다. 예: {1,2}와 {2,1}.
각 행은 길이 m인 수열이며, 전체 행은 사전순으로 반환한다.
사전순은 앞에서부터 비교하여 처음 다른 숫자가 작은 수열이 먼저 오는 순서다.

제한사항
- 1 <= m <= n <= 8
- 반환형은 int[][]이며, 숫자를 이어 붙인 정수가 아니라 각 숫자를 별도 칸에 저장한다.

입출력 예시
n=3, m=2 -> {{1,2},{1,3},{2,1},{2,3},{3,1},{3,2}}
n=1, m=1 -> {{1}}
n=8, m=8 -> 총 40320행

### 2. 편의점을 거쳐 공연장에 도착하기

집에서 출발해 공연장까지 걸어가려고 한다. 처음에는 맥주 20병을 가지고 있다.
50미터를 걷기 직전에 맥주 한 병을 마셔야 하며, 한 병으로 최대 50미터를 간다.
편의점에 도착하면 빈 병을 버리고 맥주를 다시 최대 20병까지 채울 수 있다.
한 번에 들고 있는 맥주는 20병을 넘을 수 없다.
두 좌표 사이의 이동 거리는 |x1-x2| + |y1-y2|이다.
편의점들을 필요한 순서대로 이용하여 공연장에 도착할 수 있으면 "happy",
도착할 수 없으면 "sad"를 반환하라. 최단 이동 거리를 반환하는 문제가 아니다.
home과 festival은 각각 {x,y}, stores[i]는 i번째 편의점의 {x,y}이다.

제한사항
- 0 <= stores.length <= 100
- 모든 x,y 좌표는 -32768 이상 32767 이하의 정수다.
- 원본의 테스트 케이스 하나를 solution 호출 한 번으로 전달한다.

입출력 예시
home={0,0}, stores={{1000,0},{2000,0}}, festival={3000,0} -> "happy"
집 -> 첫 편의점 -> 둘째 편의점 -> 공연장 순서로 간다.
home={0,0}, stores={}, festival={1001,0} -> "sad"
home={-500,-500}, stores={}, festival={0,0} -> "happy"

### 3. 목적지마다 처음 보낼 곳 정하기

집하장 n개 사이에 양방향 도로가 있고, roads[i]={a,b,time}은
a번과 b번 집하장 사이의 이동 시간이 time이라는 뜻이다.
각 출발 집하장에서 각 목적 집하장으로 최소 시간에 화물을 보내려고 한다.
이때 출발 직후 가장 먼저 보내야 하는 집하장 번호를 경로표에 기록하라.
전체 이동 시간이나 도착 직전의 집하장을 반환하는 문제가 아니다.
반환형은 String[][]이며 answer[a-1][b-1]에 처음 보낼 집하장 번호를 문자열로 넣는다.
출발과 목적이 같으면 "-"를 넣는다. 이동할 수 없는 쌍도 "-"로 표시한다.
최단 경로가 여러 개라면 그중 한 경로의 첫 집하장을 반환하면 된다.
원본의 경로표 출력 기호를 문자열 배열의 원소로 옮긴 형식이다.

제한사항
- 1 <= n <= 200
- 1 <= roads.length <= 10000
- 집하장 번호는 1부터 n까지이며 이동 시간은 1 이상 1000 이하이다.
- 연결된 집하장 쌍에는 양방향으로 이동할 수 있다.
- 동일 목적지의 동률에서 작은 번호를 고르는 등의 추가 우선순위는 요구하지 않는다.

입출력 예시
n=3, roads={{1,2,2},{2,3,3},{1,3,10}} ->
{{"-","2","2"},{"1","-","3"},{"2","2","-"}}
1에서3으로 직접 가면10, 2를 거치면5이므로 answer[0][2]="2"이다.
n=2, roads={{1,2,7}} -> {{"-","2"},{"1","-"}}

### 4. 복사와 붙여넣기로 목표 개수 만들기

화면에는 처음에 이모티콘이 1개 있고, 클립보드는 비어 있다.
다음 세 동작 중 하나를 선택할 때마다 1초가 걸린다.
1. 화면의 이모티콘 전체를 클립보드에 복사한다. 기존 클립보드 내용은 덮어쓴다.
2. 클립보드의 이모티콘 전체를 화면에 붙여넣는다. 화면 개수에 클립보드 개수가 더해진다.
3. 화면에서 이모티콘 한 개를 삭제한다.
일부만 복사할 수 없으며, 클립보드가 비어 있으면 붙여넣을 수 없다.
화면이 비어 있으면 삭제할 수 없다. 붙여넣거나 삭제해도 클립보드 내용은 유지된다.
화면에 정확히 target개를 만드는 데 필요한 최소 시간을 반환하라.
목표 개수를 잠시 넘겼다가 삭제하는 동작도 허용된다.

제한사항
- 2 <= target <= 1000
- 처음 화면 개수는1, 클립보드 개수는0이다.
- 복사·붙여넣기·삭제는 각각 별도의1초짜리 동작이다.

입출력 예시
target=2 -> 2
복사(화면1,저장1) -> 붙여넣기(화면2,저장1).
target=4 -> 4
target=6 -> 5
복사 -> 붙여넣기 -> 복사 -> 붙여넣기 -> 붙여넣기.
target=18 -> 8

### 5. 블록 그룹을 골라 지우고 회전하기

n*n 격자의 모든 칸에 처음에는 블록이 하나씩 놓여 있다.
-1은 검은 블록, 0은 무지개 블록, 1부터 colors까지는 일반 블록의 색 번호다.
상하좌우로 연결된 블록들로 그룹을 만든다. 그룹에는 일반 블록이 최소 하나 있어야 하고,
일반 블록은 모두 같은 색이어야 한다. 무지개 블록은 몇 개든 포함할 수 있다.
검은 블록은 포함할 수 없고, 그룹의 전체 블록 수는 최소2개여야 한다.
한 색과 무지개를 통해 더 연결되는 블록이 있으면 모두 같은 그룹에 포함한다.
무지개 블록 하나가 서로 다른 색의 후보 그룹에 각각 포함될 수 있다.

각 그룹의 '기준 블록'은 그 그룹의 일반 블록 중 행이 가장 작은 블록이며,
그런 블록이 여러 개면 열이 가장 작은 블록이다. 행·열은0부터 시작한다.
다음 순서로 그룹 하나를 선택한다.
1. 전체 블록 수가 가장 큰 그룹
2. 동률이면 무지개 블록 수가 가장 많은 그룹
3. 그래도 동률이면 기준 블록의 행이 가장 큰 그룹
4. 그래도 동률이면 기준 블록의 열이 가장 큰 그룹
기준 블록 자체는 위쪽·왼쪽에서 정하지만, 그룹끼리 비교할 때는 아래쪽·오른쪽을 우선한다.

선택할 그룹이 있는 동안 아래 과정을 반복한다.
1. 선택한 그룹 하나만 삭제하고, 블록 수가 B이면 B*B점을 얻는다.
2. 중력: 일반·무지개 블록을 아래로 내린다. 검은 블록은 움직이지 않고 다른 블록도 통과할 수 없다.
3. 격자 전체를 반시계 방향으로90도 회전한다. 검은 블록과 빈칸도 함께 회전한다.
4. 다시 중력을 적용한다.
선택 가능한 그룹이 없어지면 종료하고 총점을 반환하라.
삭제 후 빈칸은 구현에서 -2 등 별도 값으로 구분한다. 0은 빈칸이 아니다.

제한사항
- 1 <= board.length = n <= 20, 모든 행의 길이는 n이다.
- 1 <= colors <= 5
- 초기 board의 값은 -1 이상 colors 이하이며 초기 빈칸은 없다.
- 검은 블록은 중력에서는 고정이지만 회전 시에는 위치가 바뀐다.

입출력 예시
colors=1, board={{1,1},{1,1}} -> 16
colors=2, board={{1,0},{2,-1}} -> 4
크기2·무지개1인 두 후보 중 기준 행이 큰2색 그룹을 지운다.
colors=2, board={{1,-1},{-1,2}} -> 0
Main의 마지막5*5예제 -> 77
