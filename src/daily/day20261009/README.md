## 문제 풀이 영역

### 1. 감염되는 컴퓨터

컴퓨터 n대가 1번부터 n번까지 번호를 가진다.
edges[i] = {u, v}는 두 컴퓨터가 직접 연결되어 있다는 뜻이다.
연결은 양방향이며, 바이러스는 연결을 따라 계속 전파된다.
1번 컴퓨터가 감염되었을 때 추가로 감염되는 컴퓨터 수를 반환하라.
처음 감염된 1번은 반환값에서 제외한다.

제한사항
- 1 <= n <= 100
- edges에는 직접 연결된 컴퓨터 쌍이 주어진다.
- 컴퓨터 번호는 1 이상 n 이하이다.

입출력 예시
n=7, edges={{1,2},{2,3},{1,5},{5,2},{5,6},{4,7}} -> 4
n=1, edges={} -> 0

[Main1.java](Main1.java)에 실행 코드와 빈 Solution이 있습니다.

### 2. 정확한 거리의 도시

1부터 n까지의 도시와 단방향 도로가 있다. 모든 도로의 거리는 1이다.
x에서 출발했을 때 최단거리가 정확히 k인 도시 번호를 오름차순 배열로 반환하라.
해당 도시가 없으면 {-1}을 반환한다.
roads[i] = {a, b}는 a에서 b로 이동할 수 있다는 의미이다.
반대 방향 이동은 보장되지 않는다. 출발 도시까지의 최단거리는 0이다.

제한사항
- 2 <= n <= 300,000
- 1 <= roads.length <= 1,000,000
- 1 <= k <= 300,000, 1 <= x <= n
- 도로 양 끝의 도시 번호는 서로 다르다.

입출력 예시
n=4, roads={{1,2},{1,3},{2,3},{2,4}}, x=1
k=2 -> [4], k=1 -> [2,3], k=3 -> [-1]
도시 3에 길이 2인 경로가 있어도 최단거리는 1이므로 k=2의 답이 아니다.

[Main2.java](Main2.java)에 실행 코드와 빈 Solution이 있습니다.

### 3. 중복 없이 이동하기

각 칸에 영어 대문자가 적힌 직사각형 보드가 있다.
말은 왼쪽 위 (0, 0)에서 출발하며 상하좌우 인접한 칸으로 이동한다.
지금까지 지나온 경로에서 사용한 알파벳은 다시 사용할 수 없다.
시작 칸을 포함해 지날 수 있는 최대 칸 수를 반환하라.
board[r].charAt(c)가 (r, c)의 알파벳이다.

제한사항
- 행과 열의 길이는 각각 1 이상 20 이하이다.
- 모든 문자열 길이는 같고, 각 문자는 A부터 Z까지이다.

입출력 예시
{"CAAB", "ADCB"} -> 3
{"AAAA", "AAAA"} -> 1
{"ABC"} -> 3
서로 다른 칸이라도 같은 알파벳이면 이동할 수 없다.

[Main3.java](Main3.java)에 실행 코드와 빈 Solution이 있습니다.

### 4. 친구를 데리고 갈 수 있을까

1부터 n까지의 정점 사이에 양방향 도로가 있다.
민준이는 1번에서 출발해 n번으로 최단거리로 이동하려고 한다.
친구 건우는 p번 정점에 있다.
최단 경로 중 p번을 지나는 경로가 하나라도 있으면 "SAVE HIM",
없다면 "GOOD BYE"를 반환하라.
roads[i] = {a, b, c}는 a와 b를 연결하는 길이 c의 양방향 도로이다.

제한사항
- 2 <= n <= 5,000, 1 <= roads.length <= 10,000
- 1 <= p <= n, 1 <= c <= 10,000
- 중복 간선과 자기 자신을 연결하는 간선은 없다.
- 1번에서 p번과 n번으로 이동할 수 있다.

입출력 예시
n=6, roads={{1,2,1},{1,3,1},{2,3,10},{3,4,1},
           {3,5,2},{4,5,1},{5,6,1}}
p=4 -> "SAVE HIM", p=2 -> "GOOD BYE"
p=4일 때 1->3->4->5->6의 거리 4는 전체 최단거리와 같다.

[Main4.java](Main4.java)에 실행 코드와 빈 Solution이 있습니다.

### 5. 국경이 열리는 날

n*n개의 나라가 격자에 있고 population[row][col]은 그 나라의 인구수이다.
매일 아래 과정을 반복한다.
1. 상하좌우로 인접한 두 나라의 인구 차이가 l 이상 r 이하이면 국경을 연다.
   이 조건은 그날 인구 이동 전의 인구수로 판단한다.
2. 열린 국경을 통해 서로 이동할 수 있는 나라들은 하나의 연합이다.
3. 연합 내 모든 나라의 인구수를 연합의 총 인구수 / 나라 수로 바꾼다.
   나눗셈의 소수점 이하는 버린다.
4. 모든 국경을 닫고, 다음 날 다시 연합을 결정한다.
더 이상 국경을 열 수 없을 때까지 인구 이동이 발생한 일수를 반환하라.

제한사항
- 1 <= n <= 50, population은 n*n 배열이다.
- 1 <= l <= r <= 100
- 0 <= population[row][col] <= 100
- 인구 이동이 발생하는 일수는 2,000 이하이다.

입출력 예시
population={{50,30},{20,40}}, l=20, r=50 -> 1
population={{50,30},{20,40}}, l=40, r=50 -> 0
population={{50,30},{20,40}}, l=20, r=30 -> 1
population={{10,15,20},{20,30,25},{40,22,10}}, l=5, r=10 -> 2
