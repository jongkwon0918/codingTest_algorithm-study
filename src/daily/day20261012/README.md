## 문제 풀이 영역

### 1. 두 가지 방문 순서

정점 번호는 1부터 n까지이고 edges[i]={u,v}는 양방향 간선이다.
start에서 다음 두 규칙으로 탐색한 방문 순서를 각각 반환한다.
첫 번째: 현재 정점의 미방문 이웃 중 번호가 작은 정점으로 들어가 같은 규칙을 반복한다.
더 갈 곳이 없으면 이전 정점으로 돌아와 남은 이웃을 탐색한다.
두 번째: 시작 정점을 발견하고, 발견한 정점들을 발견 순서대로 처리한다.
각 정점을 처리할 때 미방문 이웃을 번호가 작은 순서로 발견 목록에 넣는다.
각 탐색에서 정점은 한 번만 방문하며, start에서 도달할 수 있는 정점만 포함한다.
answer[0]은 첫 번째 순서, answer[1]은 두 번째 순서이다.

제한사항
- 1 <= n <= 1,000
- 1 <= edges.length <= 10,000
- 정점 번호 및 start는 1 이상 n 이하이다.
- 같은 두 정점 사이에 여러 간선이 있을 수 있다.

입출력 예시
n=4, edges={{1,2},{1,3},{1,4},{2,4},{3,4}}, start=1
-> [[1,2,4,3],[1,2,3,4]]
n=4, edges={{1,2},{3,4}}, start=3 -> [[3,4],[3,4]]

### 2. 이동한 경로까지 찾기

수직선 위 start에서 target까지 이동한다.
현재 위치가 x일 때 x-1, x+1, 2*x 중 하나로 이동할 수 있고, 각각 1초가 걸린다.
최소 이동 시간과 그 시간으로 이동하는 경로 하나를 반환하라.
answer[0]={최소 시간}, answer[1]={시작 위치, ..., 목표 위치}이다.
최단 경로가 여러 개라면 아무 경로나 반환해도 된다.
시작과 목표가 같으면 시간은 0이고 경로에는 시작 위치만 들어간다.

제한사항
- 0 <= start,target <= 100,000
- 위치는 정수이며 음수 위치로 이동하지 않는다.
- 순간이동도 1초가 걸린다.

입출력 예시
start=5, target=17 -> [[4],[5,4,8,16,17]]
[[4],[5,10,9,18,17]]도 정답이다.
start=3, target=3 -> [[0],[3]]
start=2, target=0 -> [[2],[2,1,0]]

### 3. 아이템을 가장 많이 모을 시작점

지역 수 n은 items.length이고 지역 번호는 1부터 n까지이다.
items[i-1]은 i번 지역에 있는 아이템 수이다.
roads[i]={a,b,length}는 길이가 length인 양방향 도로이다.
시작 지역을 자유롭게 하나 선택할 수 있다.
선택한 시작 지역에서 최단거리가 range 이하인 모든 지역의 아이템을 얻는다.
시작 지역의 아이템도 포함하고, 각 지역의 아이템은 한 번만 센다.
얻을 수 있는 아이템 수의 최댓값을 반환하라.
range는 시작 지역에서 각 지역까지의 거리 제한이며,
여러 지역을 방문하는 전체 여행 거리의 합을 제한하는 값이 아니다.

제한사항
- 1 <= n <= 100
- 1 <= range <= 15
- 1 <= items[i] <= 30
- 1 <= roads.length <= 100
- 지역 번호는 1 이상 n 이하, 도로 길이는 1 이상 15 이하이다.
- 모든 지역이 연결되어 있다는 보장은 없다.

입출력 예시
items={5,7,8}, range=2, roads={{1,2,2},{2,3,2}} -> 20
2번에서 각 지역까지 거리가 2 이하이므로 모두 얻는다.
items={5,7,8}, range=1, 같은 roads -> 8
items={2,3,10}, range=2, roads={{1,2,1}} -> 10

### 4. 조건을 만족하는 암호 후보

중복 없는 영어 소문자 letters가 주어진다. 이 문자 중 length개를 골라 암호를 만든다.
암호의 문자는 알파벳 오름차순이어야 하며, 각 문자는 최대 한 번 사용한다.
암호에는 모음(a,e,i,o,u)이 최소 1개, 자음이 최소 2개 있어야 한다.
조건을 만족하는 모든 암호를 사전순 문자열 배열로 반환하라.
가능한 암호가 없으면 빈 배열을 반환한다.

제한사항
- 3 <= length <= letters.length() <= 15
- letters는 중복 없는 영어 소문자로 구성되며 입력 순서는 정렬되어 있지 않을 수 있다.

입출력 예시
length=3, letters="dcba" -> ["abc","abd","acd"]
length=3, letters="aei" -> []
length=4, letters="ibca" -> ["abci"]

### 5. 물이 차오르기 전에 탈출

직사각형 지도에서 고슴도치가 S에서 출발해 비버의 굴 D로 이동하려 한다.
'.'는 빈칸, '*'는 물, 'X'는 돌이다. S와 D는 각각 하나씩 있다.
고슴도치는 1분마다 상하좌우로 한 칸 이동한다.
물도 매분 상하좌우의 빈칸으로 퍼진다. 돌과 비버의 굴에는 물이 들어가지 못한다.
물은 S가 있던 칸을 포함해 고슴도치가 다닐 수 있는 빈 공간으로 퍼질 수 있다.
고슴도치는 돌이나 물이 있는 칸으로 갈 수 없고,
이번 이동 시점에 물이 차는 칸에도 이동할 수 없다.
굴까지 가는 최소 시간을 문자열로 반환하라. 불가능하면 "KAKTUS"를 반환한다.

제한사항
- 행과 열은 각각 1 이상 50 이하이다.
- 모든 문자열의 길이는 같다.
- 지도 문자는 '.', '*', 'X', 'S', 'D' 중 하나이다.
- S와 D는 각각 정확히 하나이며 물은 여러 곳에 있거나 없을 수 있다.

입출력 예시
board={"D.*","...",".S."} -> "3"
board={"D.*","...","..S"} -> "KAKTUS"
board={"SD"} -> "1"
board={"SXD"} -> "KAKTUS"
