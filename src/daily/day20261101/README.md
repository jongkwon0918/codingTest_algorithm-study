## 문제 풀이 영역

### 1. 서로 다른 다섯 사람의 연결

사람 n명은 0번부터 n-1번까지 번호가 붙어 있다.
friendships[i]={a,b}이면 두 사람이 서로 친구이다.
서로 다른 다섯 사람 A,B,C,D,E를 골라 다음 네 관계를 모두 만족할 수 있는지 판단하라.
A와 B는 친구, B와 C는 친구, C와 D는 친구, D와 E는 친구이다.
다섯 명이 모두 서로 친구일 필요는 없고, 다른 친구 관계가 추가로 있어도 된다.
가능하면1, 불가능하면0을 반환하라. 같은 사람을 두 번 사용하는 것은 안 된다.

제한사항
- 5 <= n <= 2000
- 1 <= friendships.length <= 2000
- 0 <= a,b < n이며 a와 b는 서로 다르다.
- 같은 친구 관계는 중복해서 주어지지 않는다. 관계는 양방향이다.

입출력 예시
n=5, friendships={{0,1},{1,2},{2,3},{3,4}} -> 1
0->1->2->3->4로 다섯 명을 연결할 수 있다.
n=5, friendships={{0,1},{0,2},{0,3},{0,4}} -> 0
다섯 명이 한 묶음이어도 같은 사람을 재사용하지 않고 다섯 명을 이어 갈 수는 없다.
n=6, friendships={{0,1},{1,2},{2,0},{3,4}} -> 0

### 2. 가장 안전한 빈칸의 거리

직사각형 바다에서0은 빈칸, 1은 아기 상어가 있는 칸이다.
어떤 빈칸의 안전 거리는 그 칸에서 가장 가까운 상어까지의 최단 이동 거리이다.
상하좌우와 대각선을 포함한8방향으로 한 칸씩 이동할 수 있고 한 번의 이동 거리는1이다.
모든 빈칸의 안전 거리 중 가장 큰 값을 반환하라.
상어 하나를 정해 가장 멀리 떨어지는 문제가 아니라, 각 빈칸에서 가장 가까운 상어를 기준으로 한다.

제한사항
- 2 <= sea.length <= 50
- 2 <= sea[0].length <= 50, 모든 행의 길이는 같다.
- 각 값은0 또는1이다.
- 빈칸과 상어는 각각 최소 하나 존재한다.

입출력 예시
sea={{1,0,0},{0,0,0},{0,0,0}} -> 2
(2,2)에서 대각선으로 두 번 이동하면(0,0)에 도착한다.
sea={{1,0,0},{0,0,0},{0,0,1}} -> 2
가운데의 안전 거리는1이지만(0,2)와(2,0)의 안전 거리는2다.
sea={{1,0},{0,1}} -> 1

### 3. 가장 가까운 친구로부터 멀리 살기

1번부터 n번까지의 땅 중 집을 구하려고 한다.
friends에는 세 친구가 사는 땅 번호가 주어진다. 같은 땅에 사는 친구도 있을 수 있다.
roads[i]={a,b,length}는 a와 b를 양방향으로 연결하는 길이 length의 도로이다.
한 후보 땅에서 세 친구 각각에게 가는 최단 도로 거리를 구한 뒤,
그중 가장 작은 값을 그 땅의 평가 거리로 정한다.
이 평가 거리가 가장 큰 땅의 번호를 반환하라. 동률이면 가장 작은 땅 번호를 반환한다.
친구까지의 거리 합이나, 가장 먼 친구까지의 거리를 최대화하는 문제가 아니다.

예를 들어 X에서 친구들까지 거리가3,5,4이면 평가 거리는3이다.
Y에서 거리가5,7,2이면 평가 거리는2이므로 X가 더 좋은 후보이다.

제한사항
- 1 <= n <= 100000
- friends.length == 3, 각 번호는1 이상 n 이하이다.
- n-1 <= roads.length <= 500000
- 도로 양 끝의 번호는1 이상 n 이하, 길이는1 이상10000 이하이다.

입출력 예시
n=6, friends={1,2,3},
roads={{1,4,2},{2,4,2},{3,4,2},{4,5,3},{4,6,3}} -> 5
4번의 평가 거리는2, 5번과6번은5다. 동률이므로5번을 선택한다.
n=4, friends={1,1,1}, roads={{1,2,1},{2,3,1},{3,4,1}} -> 4
n=1, friends={1,1,1}, roads={} -> 1

### 4. 열쇠를 모아 문을 지나 탈출하기

직사각형 미로에서 시작점0부터 출구1 중 어느 하나까지 가는 최소 이동 횟수를 반환하라.
상하좌우로 한 칸 이동할 때마다 횟수가1 늘어난다.
문자의 의미는 다음과 같다.
'.': 빈칸, '#': 벽, '0': 시작점, '1': 출구
'a'~'f': 해당 종류의 열쇠, 'A'~'F': 같은 알파벳의 열쇠가 있어야 통과할 수 있는 문
열쇠 칸으로 들어가면 즉시 얻고, 얻은 열쇠는 사라지지 않으며 여러 번 사용할 수 있다.
문이나 열쇠가 같은 종류로 여러 개 있을 수 있고, 문에 대응하는 열쇠가 아예 없을 수도 있다.
이미 지나간 칸도 다시 지나갈 수 있다. 탈출할 수 없으면-1을 반환하라.
이동한 경로의 열쇠만 사용할 수 있으며, 다른 경로에서 얻은 열쇠를 공유하지 않는다.

제한사항
- 1 <= maze.length <= 50
- 1 <= maze[0].length() <= 50, 모든 문자열 길이는 같다.
- 위에 설명한 문자만 등장한다.
- 시작점0은 정확히 하나, 출구1은 최소 하나 존재한다.

입출력 예시
maze={"0aA1"} -> 3
열쇠a를 얻고 문A를 지나 출구로 간다.
maze={"0A1"} -> -1
maze={"a0A1"} -> 4
왼쪽으로 가서 열쇠a를 얻은 뒤 시작 칸으로 돌아와 문A를 통과한다.
maze={"01"} -> 1

### 5. 원형 숫자판을 돌리고 같은 수 지우기

동심원 모양의 원판 n개가 있고 각 원판에는 m개의 숫자가 시계 방향으로 적혀 있다.
disks[r][c]는 r+1번 원판의 c번째 위치에 적힌 수이다.
원판 번호는1부터 n까지이며, 배열의 행 인덱스는0부터 n-1까지이다.
각 원판에서 첫 위치와 마지막 위치는 서로 인접한다.
서로 이웃한 원판에서도 같은 위치 번호의 숫자끼리 인접한다.
가장 안쪽과 가장 바깥쪽 원판은 서로 이어지지 않는다. 대각선도 인접하지 않는다.

commands[i]={x,d,k}를 입력 순서대로 적용한다.
1. 원판 번호가 x의 배수인 원판만 d방향으로 k칸 회전시킨다.
d=0은 시계 방향, d=1은 반시계 방향이다.
예: {1,2,3,4}를 시계로1칸 돌리면{4,1,2,3}, 반시계로1칸이면{2,3,4,1}.
숫자가 지워진 위치도 함께 회전하며, 다른 원판은 움직이지 않는다.
2. 전체 원판에서 인접하면서 값이 같은 숫자들을 찾는다.
그런 숫자가 하나라도 있으면 해당하는 모든 숫자를 동시에 지운다.
없으면 남아 있는 모든 숫자의 평균을 구하여 평균보다 큰 수는1 빼고, 작은 수는1 더한다.
평균과 같은 수는 유지한다. 평균은 정수로 버리지 않으며, 모든 비교는 조정 전 평균을 기준으로 한다.
지워진 칸은 이웃을 비교할 때나 평균 계산에서 제외하고, 빈칸을 건너뛰어 이웃으로 보지 않는다.
숫자가 하나도 없으면 삭제와 평균 조정을 건너뛴다.
모든 명령을 적용한 뒤 남은 수의 합을 반환하라. 숫자를 아래로 떨어뜨리는 단계는 없다.

제한사항
- 2 <= disks.length = n <= 50
- 2 <= disks[0].length = m <= 50, 모든 행의 길이는 같다.
- 초기 숫자는1 이상1000 이하이며 초기 빈칸은 없다.
- 1 <= commands.length <= 50
- 2 <= x <= n, d는0 또는1, 1 <= k < m
- 구현에서 지워진 칸을0으로 표시할 수 있다.

입출력 예시
disks={{1,1,1},{1,1,1}}, commands={{2,0,1}} -> 0
모든 숫자가 같은 이웃을 가지므로 동시에 지워진다.
disks={{1,2,3},{10,20,30}}, commands={{2,0,1}} -> 68
회전 후{{1,2,3},{30,10,20}}이며 같은 이웃이 없다.
평균11을 기준으로{{2,3,4},{29,11,19}}가 된다.
Main의4*4예제에 명령{{2,0,1}}만 적용하면30,
명령{{2,0,1},{3,1,3}}을 적용하면22이다.
