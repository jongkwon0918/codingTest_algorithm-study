### 1. 화살표를 따라 만나는 고리

1부터 n까지의 수가 한 번씩 들어 있는 순열 permutation이 있다.
정점 i에서 permutation[i-1]번 정점으로 향하는 화살표를 그린다.
화살표를 계속 따라가면 출발한 정점으로 돌아오는 고리가 만들어진다.
서로 다른 고리의 개수를 반환하라. 자기 자신으로 돌아오는 정점도 고리 하나이다.
배열 인덱스는 0부터지만 정점 번호는 1부터이다.

제한사항
- 2 <= permutation.length <= 1,000
- permutation은 1부터 n까지의 수를 중복 없이 포함한다.
- 원본의 테스트 케이스 하나를 solution 호출 한 번으로 전달한다.

입출력 예시
permutation={2,1,3} -> 2
고리는 1->2->1과 3->3이다.
permutation={2,3,4,1} -> 1
permutation={1,2,3,4} -> 4

### 2. 배송에 필요한 최소 비용

1번 헛간에서 n번 헛간까지 택배를 배달한다.
roads[i]={a,b,cost}는 a와 b를 잇는 양방향 길과 그 길에서 필요한 비용이다.
길마다 비용이 다르고, 비용이 0인 길도 있다.
배달 경로에서 지나는 길들의 비용 합이 최소가 되도록 했을 때 그 비용을 반환하라.
같은 두 헛간 사이에 여러 길이 있을 수 있다.

제한사항
- 1 <= n <= 50,000
- 1 <= roads.length <= 50,000
- 1 <= a,b <= n
- 0 <= cost <= 1,000

입출력 예시
n=4, roads={{1,2,0},{2,4,3},{1,3,1},{3,4,1}} -> 2
1->3->4의 비용은 1+1=2이다.
n=3, roads={{1,2,5},{2,3,2},{1,3,20}} -> 7

### 3. 사다리와 뱀을 거쳐 도착하기

1번부터 100번까지의 칸이 있고 1번에서 시작한다.
주사위를 한 번 굴릴 때 1~6 중 원하는 수를 골라 그만큼 앞으로 이동한다.
100번을 넘는 이동은 할 수 없다.
도착한 칸이 사다리 시작점이면 사다리 끝으로, 뱀 시작점이면 뱀 끝으로 반드시 이동한다.
사다리·뱀을 타는 데에는 주사위를 추가로 굴리지 않는다.
ladders[i]={시작,끝}, snakes[i]={시작,끝}이다.
100번에 도착하기 위한 최소 주사위 횟수를 반환하라.

제한사항
- 1 <= ladders.length <= 15, 1 <= snakes.length <= 15
- 사다리는 시작<끝, 뱀은 시작>끝이다.
- 1번과 100번에는 사다리나 뱀이 없다.
- 각 칸에는 최대 하나의 사다리 또는 뱀이 있고 두 종류가 동시에 있지 않는다.
- 항상 100번에 도착할 수 있는 입력이 주어진다.

입출력 예시
ladders={{2,98}}, snakes={{99,3}} -> 2
1->2에서 사다리를 타고98, 다음 주사위2로100에 도착한다.
ladders={{2,90}}, snakes={{91,3}} -> 3

### 4. 계란을 부딪쳐 최대한 깨기

계란이 왼쪽부터 놓여 있고 eggs[i]={내구도,무게}이다.
왼쪽 계란부터 차례로 한 번씩 손에 들 차례가 온다.
손에 든 계란이 깨져 있으면 다음 계란 차례로 넘어간다.
깨지지 않았다면 다른 깨지지 않은 계란 하나를 골라 반드시 한 번 부딪친다.
상대 계란이 하나도 없다면 부딪치지 않고 다음 차례로 넘어간다.
부딪치면 두 계란의 내구도가 동시에 상대 계란의 무게만큼 감소한다.
내구도가 0 이하가 된 계란은 깨진 것이다.
부딪친 뒤에는 손에 들었던 계란의 다음 위치 계란 차례로 넘어간다.
모든 차례가 끝났을 때 깨진 계란 수의 최댓값을 반환하라.
무게는 변하지 않으며, 앞서 차례가 지난 계란도 살아 있다면 상대가 될 수 있다.

제한사항
- 1 <= eggs.length <= 8
- 1 <= 내구도,무게 <= 300

입출력 예시
eggs={{1,1},{1,1}} -> 2
eggs={{10,1},{10,1}} -> 0
eggs={{1,1},{1,1},{1,1}} -> 2
eggs={{5,3}} -> 0

### 5. 여러 벽을 부수며 도착하기

직사각형 지도에서 0은 빈칸, 1은 벽이다.
왼쪽 위 (0,0)에서 오른쪽 아래까지 상하좌우로 이동한다.
벽은 전체 경로에서 최대 k개까지 부수고 그 칸으로 이동할 수 있다.
최단 경로의 길이는 지나간 칸 수이며 시작 칸과 도착 칸도 포함한다.
도착할 수 없으면 -1을 반환하라.
시작점과 도착점이 같으면 길이는 1이다.

제한사항
- 행과 열은 각각 1 이상 1,000 이하이다.
- 1 <= k <= 10
- 모든 행의 길이는 같으며 값은 0 또는 1이다.
- 시작점과 도착점은 항상 0이다.

입출력 예시
map={{0,1,1,0}}, k=1 -> -1
같은 map, k=2 -> 4
map={{0,0,0},{1,1,0},{0,0,0}}, k=1 -> 5
map={{0}}, k=1 -> 1
