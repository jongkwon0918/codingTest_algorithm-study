## 문제 풀이 영역

### 1. 조건을 만족하는 숫자 선택

정수 배열 numbers에서 원소를 하나 이상 골라 합이 target이 되는 경우의 수를 반환하라.
각 원소는 한 번만 고를 수 있고, 고른 원소의 원래 순서는 유지한다.
연속된 원소만 고를 필요는 없다. 아무것도 고르지 않는 경우는 제외한다.
값이 같아도 배열의 위치가 다르면 서로 다른 선택으로 센다.

제한사항
- 1 <= numbers.length <= 20
- -100,000 <= numbers[i] <= 100,000
- -1,000,000 <= target <= 1,000,000

입출력 예시
numbers={-7,-3,-2,5,8}, target=0 -> 1
인덱스 1,2,3의 {-3,-2,5}를 고르면 합이 0이다.
numbers={0,0}, target=0 -> 3
첫째만, 둘째만, 둘 다 고르는 세 가지이다.
numbers={1,1,1}, target=2 -> 3

### 2. 가장 멀리 떨어진 두 육지

직사각형 지도에서 'L'은 육지, 'W'는 바다이다.
상하좌우로 인접한 육지로만 이동할 수 있고 한 칸 이동에 1시간이 걸린다.
육지 두 곳에 보물이 있으며, 두 보물 사이의 최단 이동 시간이 가장 길어지는 곳에 묻혀 있다.
서로 육지로 연결되어 이동할 수 있는 두 칸을 골랐을 때,
두 칸 사이 최단거리들 중 가장 큰 값을 반환하라.
일부러 돌아가는 경로의 길이를 최대화하는 문제가 아니다.

제한사항
- 행과 열의 길이는 각각 1 이상 50 이하이다.
- 모든 행의 길이는 같고 문자는 L 또는 W이다.
- 서로 이동 가능한 육지 두 곳이 있는 지도를 대상으로 한다.

입출력 예시
island={"LLL","LWL","LLL"} -> 4
육지 고리의 반대편 두 칸 사이 최단거리는 4이다. 한 바퀴 도는 길이8을 반환하지 않는다.
island={"LLLLL"} -> 4
island={"LLWLL"} -> 1

### 3. 최소 비용과 실제 이동 경로

1부터 n까지의 도시와 단방향 버스 노선이 있다.
buses[i]={from,to,cost}는 from에서 to로 가는 버스와 비용을 의미한다.
start에서 target까지의 최소 비용과, 그 비용으로 이동하는 실제 도시 경로를 반환하라.
반환 형식은 answer[0]={최소 비용, 경로에 포함된 도시 수},
answer[1]={출발 도시,...,도착 도시}이다.
도시 수에는 출발과 도착도 포함한다.
최소 비용 경로가 여러 개면 그중 아무 경로나 반환해도 된다.
같은 두 도시 사이에 여러 버스가 있을 수 있고 반대 방향 이동은 보장되지 않는다.

제한사항
- 1 <= n <= 1,000, 1 <= buses.length <= 100,000
- 도시 번호는 1 이상 n 이하이다.
- 0 <= cost < 100,000
- start에서 target까지 이동할 수 있다.

입출력 예시
n=4, buses={{1,2,2},{2,4,3},{1,3,1},{3,4,8}}, start=1,target=4
-> {{5,3},{1,2,4}}
n=3, buses={{1,2,0},{2,3,4},{1,3,9}}, start=1,target=3
-> {{4,3},{1,2,3}}

### 4. 카메라 방향으로 사각지대 줄이기

직사각형 사무실에서 0은 빈칸, 6은 벽, 1~5는 카메라 종류이다.
각 카메라는 자기 위치에서 다음 방향들을 동시에 직선으로 감시한다.
- 1번: 한 방향
- 2번: 서로 반대인 두 방향
- 3번: 서로 직각인 두 방향
- 4번: 네 방향 중 세 방향
- 5번: 상하좌우 네 방향
카메라는 위치를 바꿀 수 없고, 각자 90도 단위로 회전시킬 수 있다.
감시는 벽이나 사무실 끝까지 이어진다. 벽은 통과할 수 없지만 다른 카메라는 통과한다.
여러 카메라가 같은 칸을 감시해도 된다.
모든 카메라의 방향을 정했을 때 아무 카메라도 감시하지 못하는 빈칸 수의 최솟값을 반환하라.
벽과 카메라가 있는 칸은 빈칸 수에 포함하지 않는다.

제한사항
- 행과 열의 길이는 각각 1 이상 8 이하이다.
- 모든 행 길이는 같고 값은 0 이상 6 이하이다.
- 카메라는 최대 8개이다.

입출력 예시
office={{0,0,0},{0,5,0},{0,0,0}} -> 4
가운데 5번은 십자 네 칸을 감시하고 모서리 네 칸은 남는다.
office={{1,0,6,0}} -> 1
벽 뒤의 빈칸은 볼 수 없다.
office={{1,0,1}} -> 0

### 5. 같은 색을 지우고 아래로 떨어뜨리기

12행6열의 판에 색깔 블록이 놓여 있다. '.'는 빈칸이고 R,G,B,P,Y는 색깔이다.
같은 색 블록이 상하좌우로 4개 이상 연결된 그룹은 그 그룹 전체가 사라진다.
현재 사라질 수 있는 그룹은 색이나 위치와 관계없이 모두 동시에 사라진다.
그다음 남은 블록들은 같은 열에서 아래로 떨어져 빈 공간을 채운다.
낙하 후 다시 4개 이상 연결된 그룹이 생기면 같은 처리를 반복한다.
그룹 여러 개가 동시에 사라져도 연쇄는 한 번만 증가한다.
더 이상 사라질 그룹이 없을 때까지 일어나는 연쇄 횟수를 반환하라.
대각선 연결은 인정하지 않으며 새 블록을 추가하지 않는다.

제한사항
- field는 길이6인 문자열12개이다.
- 문자는 .,R,G,B,P,Y 중 하나이다.
- 초기 판은 이미 아래로 떨어진 상태라 블록 바로 아래에 빈칸이 있는 경우는 없다.

입출력 예시
모든 칸이 '.' -> 0
맨 아래 행만 "RRRR.."이고 나머지는 모두 "......" -> 1
맨 아래 두 행이 "....GG","RRRRGG"이고 나머지는 모두 빈칸 -> 1
빨강4개와 초록4개가 동시에 사라지므로2가 아니라1이다.
아래 Main의 마지막 예제 -> 3
