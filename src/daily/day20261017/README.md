### 1. 적힌 수만큼 점프하기

정사각형 보드의 왼쪽 위에서 출발해 오른쪽 아래로 가려 한다.
현재 칸에 적힌 수만큼 정확히 오른쪽 또는 아래로 점프할 수 있다.
적힌 수보다 짧게 또는 길게 이동하거나, 위·왼쪽으로 이동할 수 없다.
보드 밖으로 나가는 이동은 실패이다.
오른쪽 아래에 도달할 수 있으면 "HaruHaru", 없으면 "Hing"를 반환하라.
목표 칸에는 -1이 적혀 있다. 다른 칸에는 0이 적혀 있을 수도 있다.

제한사항
- 보드는 n*n이고 2 <= n <= 3이다.
- 목표 이외의 칸 값은 0 이상 100 이하이다.
- 목표는 오른쪽 아래 한 칸이다.

입출력 예시
board={{1,1},{1,-1}} -> "HaruHaru"
board={{2,1},{1,-1}} -> "Hing"
board={{0,1},{1,-1}} -> "Hing"

### 2. 여섯 방향으로 움직이는 말

n*n 보드에 놓인 말을 start={행,열}에서 target={행,열}로 이동한다.
한 번의 이동에서 행·열 변화량은 다음 여섯 가지 중 하나이다.
(-2,-1),(-2,1),(0,-2),(0,2),(2,-1),(2,1)
다른 방향으로는 이동할 수 없고 보드 밖으로 나갈 수 없다.
최소 이동 횟수를 반환하라. 도달할 수 없으면 -1이다.
시작과 목표가 같으면 0이다. 장애물은 없다.

제한사항
- 5 <= n <= 200
- 좌표의 행과 열은 0 이상 n 미만이다.
- start와 target의 길이는 각각 2이다.

입출력 예시
n=5, start={0,0}, target={2,1} -> 1
n=5, start={0,0}, target={4,2} -> 2
n=5, start={0,0}, target={1,0} -> -1
n=5, start={2,2}, target={2,2} -> 0

### 3. 하루 이동 제한 안에서 떡 돌리기

집 번호는 0부터 n-1까지이고 home이 내 집이다.
roads[i]={a,b,length}는 양방향 도로이다.
나머지 모든 이웃집에 떡을 하나씩 배달하려 한다.
떡은 한 번에 하나만 들고 갈 수 있어, 한 집에 배달할 때마다 반드시 내 집으로 돌아온다.
내 집에서의 최단거리가 가까운 이웃집부터 방문한다.
하루 동안 걸은 거리의 합은 dailyLimit 이하이고, 매일 내 집에서 출발해 내 집에서 끝낸다.
모든 집에 배달하는 데 필요한 최소 일수를 반환하라.
도달할 수 없는 집이 있거나 어떤 한 집의 왕복 거리도 하루 제한 안에 들어오지 못하면 -1이다.

제한사항
- 2 <= n <= 1,000
- 1 <= roads.length <= 100,000
- 1 <= dailyLimit <= 10,000,000
- 0 <= home,a,b < n, a != b
- 1 <= length <= 10,000
- 같은 두 집 사이의 도로는 하나이다.

입출력 예시
n=4, roads={{0,1,1},{0,2,2},{0,3,3}}, dailyLimit=8, home=0 -> 2
왕복 거리는 2,4,6이다. 첫날2+4, 둘째날6을 이동한다.
같은 도로, dailyLimit=5, home=0 -> -1
n=3, roads={{0,1,1}}, dailyLimit=10, home=0 -> -1

### 4. 위아래 숫자 집합 맞추기

두 행의 표가 있다. 위 행은 1,2,...,n이고 아래 행은 numbers이다.
위 행에서 몇 개의 숫자를 선택하면, 같은 열의 아래 숫자들도 함께 선택된다.
선택한 위 숫자의 집합과 아래 숫자의 집합이 같도록, 최대한 많은 위 숫자를 선택하라.
선택한 위 숫자들을 오름차순 배열로 반환한다. 배열 길이가 선택한 개수이다.
아래 행은 순열이 아니며 같은 숫자가 여러 번 나올 수 있다.

제한사항
- 1 <= numbers.length <= 100
- 1 <= numbers[i] <= n
- numbers[i-1]은 위 숫자 i의 바로 아래 숫자이다.

입출력 예시
numbers={3,1,1,5,5,4,6} -> [1,3,5]
선택한 위 집합 {1,3,5}, 아래 숫자는 {3,1,5}로 같은 집합이다.
numbers={2,3,2} -> [2,3]
numbers={1,2,3} -> [1,2,3]

### 5. 가장 짧은 다리 하나 놓기

n*n 지도에서 1은 육지, 0은 바다이다.
상하좌우로 붙어 있는 육지들은 하나의 섬이다. 대각선만 맞닿으면 다른 섬이다.
바다 칸에 다리를 놓아 서로 다른 섬 두 개를 연결하려 한다.
다리는 상하좌우로 이어져야 하며, 길이는 다리를 놓은 바다 칸 수이다.
어떤 두 섬을 선택해도 되며, 모든 섬을 연결할 필요는 없다.
가장 짧은 다리 하나의 길이를 반환하라.

제한사항
- 1 <= n <= 100, map은 n*n 배열이다.
- 값은 0 또는 1이며 항상 두 개 이상의 섬이 있다.
- 다리는 바다에만 놓고 육지는 길이에 포함하지 않는다.

입출력 예시
map={{1,0,1},{1,0,0},{0,0,0}} -> 1
map={{1,0,0},{0,0,0},{0,0,1}} -> 3
map={{1,0},{0,1}} -> 1
