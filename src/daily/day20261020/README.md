기존 출제를 제외한 새 문제5개입니다. 기본·중급2개, 조건 응용2개, 복합 골드1개로 구성했습니다.

## 문제 풀이 영역

### 1. 방향에 따라 이어지는 판자

직사각형 바닥이 '-'와 '|'로 표시되어 있다.
같은 행에서 좌우로 이어지는 '-'들은 하나의 나무 판자이다.
같은 열에서 위아래로 이어지는 '|'들은 하나의 나무 판자이다.
서로 다른 방향의 문자는 붙어 있어도 같은 판자가 아니다.
필요한 나무 판자의 개수를 반환하라.

제한사항
- 행과 열은 각각 1 이상 50 이하이다.
- 모든 문자열 길이는 같고 문자는 '-' 또는 '|'이다.

입출력 예시
floor={"---","---"} -> 2
floor={"||","||"} -> 2
floor={"-|-","-|-"} -> 5
가운데 세로 판자1개와 양쪽 행별 가로 판자4개이다.

### 2. 출발점에서 모든 정점까지

정점은 1번부터 n번까지이고 edges[i]={u,v,weight}는 u에서 v로 가는 단방향 간선이다.
start에서 각 정점까지의 최단거리를 번호 순서의 문자열 배열로 반환하라.
answer[i-1]은 i번 정점의 결과이다. 시작점은 "0", 도달할 수 없으면 "INF"이다.
같은 두 정점 사이에 여러 간선이 있을 수 있다.

제한사항
- 1 <= n <= 20,000
- 1 <= edges.length <= 300,000
- 정점 번호와 start는 1 이상 n 이하이다.
- 1 <= weight <= 10

입출력 예시
n=5, edges={{1,2,2},{1,3,3},{2,3,1},{2,4,5},{3,4,1}}, start=1
-> ["0","2","3","4","INF"]
n=3, edges={{1,2,5},{1,2,1}}, start=2 -> ["INF","0","INF"]

### 3. 층을 오가며 출구 찾기

building[층][행]은 해당 층의 한 행을 나타내는 문자열이다.
문자열의 열 위치가 하나의 칸이다. 'S'는 출발점, 'E'는 출구, '.'는 빈칸, '#'는 벽이다.
동서남북과 위층·아래층의 인접 칸으로 이동하며 한 번에 1분이 걸린다.
대각선으로 이동하거나 건물 밖으로 나갈 수 없고 벽은 통과할 수 없다.
탈출 가능하면 "Escaped in x minute(s)." 형식으로 최소 시간을 반환하라.
불가능하면 "Trapped!"를 반환한다.

제한사항
- 층 수·각 층의 행 수·열 수는 각각 1 이상 30 이하이다.
- 모든 층의 크기는 같으며 S와 E는 각각 하나이다.
- 원본의 테스트 케이스 하나를 solution 호출 한 번으로 전달한다.

입출력 예시
building={{"S."},{"#E"}} -> "Escaped in 2 minute(s)."
0층에서 오른쪽으로 이동하고, 같은 행·열의 1층 출구로 이동한다.
building={{"S#E"}} -> "Trapped!"
building={{"S"},{"E"}} -> "Escaped in 1 minute(s)."

### 4. 세 장애물로 시선 가리기

n*n 복도에서 'T'는 선생님, 'S'는 학생, 'X'는 빈칸이다.
각 선생님은 상하좌우 직선 방향으로 끝까지 학생을 볼 수 있다.
빈칸 세 곳을 골라 장애물 'O'를 정확히 3개 설치한다.
장애물은 그 뒤의 시선을 막으며 학생이나 선생님이 있는 칸에는 설치할 수 없다.
선생님이 다른 선생님을 만났다고 시선이 막히지는 않는다.
모든 학생을 모든 선생님의 시선에서 숨길 수 있으면 "YES", 없으면 "NO"를 반환하라.

제한사항
- 3 <= n <= 6, 모든 문자열 길이는 n이다.
- 선생님은 1 이상 5 이하, 학생은 1 이상 30 이하이다.
- 빈칸은 항상 3개 이상이다.
- 입력 문자는 T,S,X 중 하나이다.

입출력 예시
hallway={"TXS","XXX","XXX"} -> "YES"
(0,1)에 장애물을 두고 나머지 두 개를 다른 빈칸에 둔다.
hallway={"TSX","XXX","XXX"} -> "NO"
선생님과 학생 사이에 장애물을 둘 빈칸이 없다.
hallway={"TXX","XXX","XXS"} -> "YES"

### 5. 길을 건너지 않고 만날 수 있을까

n*n 목초지에서 소들은 상하좌우 인접 칸으로 자유롭게 이동할 수 있다.
다만 roads[i]={r1,c1,r2,c2}로 주어진 인접한 두 칸 사이에는 길이 놓여 있다.
그 사이를 직접 이동하려면 길을 건너야 한다. 길은 양방향으로 적용된다.
다른 경로로 돌아서 길을 한 번도 건너지 않고 이동할 수 있다면 만나도 된다.
cows[i]={행,열}은 소 한 마리의 위치이며 모든 소의 위치는 서로 다르다.
길을 하나 이상 건너지 않고서는 만날 수 없는 소의 쌍 개수를 반환하라.
(A,B)와 (B,A)는 같은 쌍이며 자기 자신은 세지 않는다.

제한사항
- 2 <= n <= 100
- 1 <= cows.length <= 100, cows.length <= n*n
- roads의 각 두 칸은 상하좌우로 인접한다.
- roads와 cows의 좌표는 모두 1 이상 n 이하이다.
- 길이 없는 두 인접 칸 사이에는 자유롭게 이동할 수 있다.

입출력 예시
n=3, roads={{2,2,2,3},{3,3,3,2},{3,3,2,3}},
cows={{3,3},{2,2},{2,3}} -> 2
(3,3)의 소가 다른 두 소와 길 없이 만나지 못한다.
n=2, roads={{1,1,1,2}}, cows={{1,1},{1,2}} -> 0
아래쪽 두 칸을 거쳐 돌아갈 수 있다.
